A rounded surface container (2xl radius, soft shadow). Base for feature, pricing, and stat cards.

```jsx
<Card hoverable padding={28}>
  <h3>Aplikacje internetowe</h3>
  <p>Skrojone pod oczekiwania klienta.</p>
</Card>
<Card variant="glass">…overlay…</Card>
```

Variants: `default`, `feature` (2px border), `glass` (blur), `elevated`. Set `hoverable` for the lift + purple-glow border interaction used across the marketing site.
