The standard section header used across the marketing site: mono eyebrow, large gradient display title, muted lead.

```jsx
<SectionHeading
  eyebrow="// Oferta"
  title="Czego szukasz?"
  description="Strony, sklepy i aplikacje skrojone pod Twój biznes."
/>
```

`align` = left | center | right. Set `gradient={false}` for a plain foreground title (e.g. on the colored stat band).
