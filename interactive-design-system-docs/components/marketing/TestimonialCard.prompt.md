Client testimonial card with star rating, quote, and author.

```jsx
<TestimonialCard
  rating={5}
  text="Strona zwiększyła liczbę zapytań o 200% w pierwszym miesiącu."
  name="Anna Kowalska"
  role="Właściciel sklepu z odzieżą"
/>
```

Avatar falls back to initials on a gradient chip when no `avatar` URL is given.
